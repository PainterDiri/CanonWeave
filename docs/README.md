## 文档职责

| 文档 | 作用 |
| --- | --- |
| [当前工程交接](handoffs/2026-10-21-current-state.md) | 固定日期的代码基线、已完成内容、验证结果、已知限制和下一步 |
| [当前架构](ARCHITECTURE.md) | 前后端边界、主要数据流、核心模块和扩展位置 |

| [开发进度](../开发进度.md) | 按日期记录实际交付和限制，不替代规格或交接 |
| [README](../README.md) | 用户使用说明、功能入口和启动方式 |

## 文档维护规则

- 产品目标或不可违反的约束变化：更新开发规格。
- 已完成能力和验收结果变化：追加开发进度。
- 代码基线、关键文件、测试命令或下一步变化：新建日期化交接，不覆盖旧交接。
- 数据库结构变化：更新数据模型并新增迁移。
- README 只描述用户已能使用的行为，不把计划和占位写成完成。
